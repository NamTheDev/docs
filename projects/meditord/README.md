# MeditorD

MeditorD is a self-hosted Markdown editor and media archive. It combines a nostalgic interface with a Bun/TypeScript server, SQLite storage and folder-based organization.

[Source repository](https://github.com/NamTheDev/MeditorD)

## Documentation

- [Editing and archiving](USAGE.md)
- [Technical architecture and development](DEVELOPMENT.md)

MeditorD retains its own design system. Its Windows 95/98-inspired editor and archive, masonry gallery and Catppuccin palette are documented in the original project's resources. It is explicitly exempt from util's Bootstrap-first visual-design requirement.
