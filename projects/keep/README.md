# keep

keep is a local-first browser notes application. It supports notes, checklists, labels, reminders, archive, recycle bin and JSON backups. Notes and preferences are stored in the browser without an account or hosted synchronization service.

[Open keep](https://namthedev.github.io/keep/) · [Source repository](https://github.com/NamTheDev/keep)
