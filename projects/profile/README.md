# Profile

Profile is a static personal documentation site with an encyclopedia-style reading layout. It renders Markdown articles, builds a hierarchical table of contents, and presents creative and software projects.

[Open Profile](https://namthedev.github.io/profile/) · [Source repository](https://github.com/NamTheDev/profile)

## Documentation

- [Using and editing Profile](USAGE.md)
- [Development and architecture](DEVELOPMENT.md)

The project catalogue displays compact GitHub metadata cards and Open Graph previews, plus YouTube upload thumbnail lists. It does not embed interactive applications or full video players.
