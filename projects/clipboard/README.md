# clipboard

clipboard is a temporary shared text vault application. It uses short room IDs for sharing text between devices, with separate owner and guest capabilities.

[Open clipboard](https://namthedev.github.io/clipboard/) · [Source repository](https://github.com/NamTheDev/clipboard)

## Documentation

- [User guide](USAGE.md)
- [Architecture and development](DEVELOPMENT.md)

The public frontend is hosted on GitHub Pages. A separate Node.js/SQLite backend is necessary for cross-device sharing.
