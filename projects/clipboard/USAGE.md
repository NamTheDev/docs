# clipboard — User guide

## Create or join a vault

1. Open clipboard and choose Create vault or Join vault.
2. Share the six-character vault ID or copied link with the other device.
3. Use New item or Paste text to add snippets as the owner.
4. Select an item to view or copy its text.

Guests can read and copy. The owner can edit or delete items and delete the vault. The sidebar also includes refresh, copy ID, copy link, leave vault and settings.

## Expiry and preferences

Vaults expire after 24 hours or seven days. Settings include default expiry, theme and automatic refresh (off, 5, 15 or 30 seconds).

## Privacy

Vault IDs are access codes, not passwords. Anyone with a valid ID can read the contents. Vault contents are not end-to-end encrypted. Do not use the service for passwords or other sensitive records. The owner token stays in the creator browser and is not part of shared links.

If a vault cannot be opened, confirm its ID, expiration and backend availability. If copy/paste fails, check the browser's clipboard permission and use manual copy/paste where necessary.
